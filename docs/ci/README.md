# Optional Windows CI template

`windows-tests.yml` is a reference template, not an active GitHub Actions workflow.

The initial publication credential does not have permission to write workflow files. Source and tests can still be reviewed in the PR without granting additional permissions.

A repository owner may review this template and enable it separately under `.github/workflows/` using an appropriately authorized GitHub session. Until then, the documented local test results are not cloud CI results. No secrets or real upstream credentials are needed by the synthetic test suite.
